# گزارش بررسی Lastsecond و شکاف‌های Hani

- **تاریخ:** 2026-11-12
- **هدف:** بررسی دقیق مدل محصول/جریان Lastsecond و مقایسه با معماری فعلی Hani
- **وضعیت:** گزارش تحلیلی — هیچ تغییر کدی در این مرحله انجام نشده است

## ۱. روش بررسی و محدودیت‌ها

صفحات عمومی زیر با مرورگر واقعی بررسی شدند:

- `/` — خانه
- `/tours` — لیست تورها
- صفحه جزئیات تور (نمونه: تور استانبول و تور یزد)
- `/hotels` — لیست هتل‌ها
- صفحه جزئیات هتل (نمونه: هتل داد یزد)
- `/visa` — لیست ویزاها
- صفحه جزئیات ویزا (نمونه: ویزای ژاپن)
- `/flights` — بلیط هواپیما
- `/safarsaz` — سفرساز / درخواست سفر
- `/blind-tour` — بلایندتور
- `/itineraries` — سفرنامه‌ها
- `/attractions` — جاذبه‌ها
- `/restaurants` — رستوران‌ها
- `/videos` — ویدیوها
- `/auth/login` و `/auth/register`
- `/pages/advertisement`
- `robots.txt`

**محدودیت:** پنل کاربری، پنل آژانس، فرم‌های بعد از ورود، Checkout و درگاه پرداخت واقعی بررسی نشدند؛ برای این بخش‌ها فقط نقاط ورود عمومی و متن‌های راهنما بررسی شده است.

## ۲. یافته‌های کلیدی صفحه‌به‌صفحه

### ۲.۱. خانه

Lastsecond یک مارکت‌پلیس مصرف‌محور است، نه فقط یک لیست تور:

- جستجوی اصلی: تور خارجی/داخلی، مبدا، مقصد، تاریخ رفت/برگشت، مدت اقامت، هتل
- تورهای ویژه، لحظه آخری، اقساطی
- تورهای خارجی/داخلی
- ویزا
- هتل
- سفرساز
- سفر به ناکجا
- بلایندتور
- سفرنامه
- بلاگ
- رستوران‌ها
- جاذبه‌ها
- ویدیو
- ورود/عضویت
- خبرنامه پیامکی و ثبت شماره تماس برای مشاوره
- تورهای چندارزی: مثلاً `135,000,000 تومان + 1,390 دلار`

**نکته مهم:** چندارزی بودن در همین صفحه دیده می‌شود و ADR-0024 را تأیید می‌کند.

### ۲.۲. لیست تورها

ویژگی‌های دیده‌شده:

- فیلتر مبدا، مقصد، تاریخ، مدت، هتل
- دسته‌بندی مقصد و مبدا
- تورهای پرفروش/لحظه آخری/اقساطی
- تور از شهرهای مختلف
- تورهای ایران‌گردی
- کد آژانس/کد تور
- قیمت شروع از
- نمایش قیمت به تومان و بعضاً دلار
- SEO برای دسته‌بندی‌ها

علاوه بر این، `robots.txt` وجود این فیلترها را نشان می‌دهد:

`adults`, `agencies`, `airlines`, `amenities`, `bundle`, `cabin`, `categories`, `children`, `companies`, `dailytriptype`, `departureDate`, `discountedTours`, `duration`, `durations`, `endDate`, `endRange`, `eventId`, `eventType`, `facilities`, `filter`, `grades`, `hotelGrades`, `hotelKeywords`, `hotelReviewScore`, `hotelRoomTypes`, `hotelServices`, `hotel`, `infants`, `itinerary`, `keywords`, `label`, `limit`, `locations`, `maxPrice`, `mealTypes`, `minPrice`, `months`, `nextUrl`, `onlineReservation`, `onlineOnly`, `priceRanges`, `p`, `q`, `refine`, `restaurantTypes`, `returnDate`, `review_category`, `review_period`, `score`, `search`, `searchId`, `search_location_id`, `search_type`, `sort`, `sources`, `startDate`, `startRange`, `tourTypes`, `travelTypes`, `type`, `vehicleTypes`, `violable_id`, `violable_type`.

این یعنی Lastsecond یک **Faceted Search** واقعی دارد؛ Hani فعلاً فقط `destinationSlug/page/pageSize` دارد.

### ۲.۳. جزئیات تور

صفحه تور بسیار غنی است:

- Breadcrumb: تورها → کشور → شهر → تور
- عنوان، امتیاز، تعداد رأی
- توضیحات تور
- «در یک نگاه»:
  - شهرها
  - محل حرکت
  - درجه سختی
  - تعداد روز
  - زمان رفت/برگشت
  - نوع تور
  - نوع اقامتگاه
  - وسیله نقلیه اصلی/محلی
  - وعده‌های غذایی
- نقشه Leaflet
- تورهای مرتبط بر اساس مقصد/نوع
- برنامه سفر روزبه‌روز
- جاذبه‌های هر روز
- جدول پذیرایی و اقامت
- خدمات تور
- اطلاعات تکمیلی
- لوازم مورد نیاز
- قوانین و مقررات / بازگشت وجه
- تاریخ‌های تور و وضعیت تکمیل ظرفیت
- کد آژانس و کد تور
- هتل‌ها و قیمت‌ها:
  - چند هتل برای یک تور
  - هر هتل با ستاره، امتیاز، تعداد نقد
  - صبحانه/BB
  - قیمت دو تخته، یک تخته، سه تخته
  - کودک با تخت، کودک بدون تخت، نوزاد
- جزئیات پرواز:
  - ایرلاین
  - فرودگاه مبدا/مقصد
  - ساعت
  - مدت
  - کلاس `ECONOMY`
  - بار مجاز
- اطلاعات آژانس:
  - نام آژانس

- شرایط اقساطی
- «اعلام مغایرت قیمت»
- مدارک لازم
- تورهای مشابه
- تماس با پشتیبانی

**نکته مهم:** Lastsecond در بسیاری از تورها فروش آنلاین ندارد و از مدل «تماس با آژانس / درخواست» استفاده می‌کند. فیلتر `onlineReservation` هم وجود دارد؛ یعنی هر دو مدل پشتیبانی می‌شوند.

### ۲.۴. هتل‌ها

لیست:

- حدود ۱۰٬۰۰۰ هتل

جزئیات هتل:

- اطلاعات هتل
- امکانات
- گالری تصاویر کاربران

  - کیفیت غذا

  - منطقه
  - ارزش قیمت
- بازه زمانی نقدها

- مرتب‌سازی نقدها

**نکته:** ویزا در Lastsecond یک سرویس درخواستی/مشاوره‌ای است، نه یک رزرو آنی.

## ۴. نتیجه‌گیری معماری

### ۴.۱. بزرگ‌ترین شکاف، «محتوای تور» و «مدل قیمت» است

مدل فعلی Hani:

- `TourProduct` = عنوان/خلاصه/توضیح/مدت/نوع/مقصد
- `AgencyOffer` = یک BasePrice
- `TourDeparture` = قیمت اتاق + ظرفیت

مدل Lastsecond:

- یک تور = محتوای غنی + چند هتل + چند اتاق + چند ایرلاین + چند تاریخ + چند قیمت + خدمات + قوانین
- قیمت = ترکیب هتل + اتاق + MealPlan + پرواز + تاریخ + ارز

**Hani بدون `TourContent` و `OfferAccommodationOption`/`OfferFlightOption` نمی‌تواند به رقابت نزدیک شود.**

### ۴.۲. Hani باید دو موتور جدا داشته باشد

1. **Booking Engine** برای Online
2. **Request/Lead Engine** برای ReservationRequest، هتل استعلامی، ویزا و سفرساز

این دو نباید در یک `Order` ساده ادغام شوند. ADR-0024 BookingMode را شروع کرده، اما Lead/RFQ یک Bounded Context جداگانه لازم دارد.

### ۴.۳. اولویت‌بندی فعلی Phase 3 اشتباه است

Hani در Phase 3 سراغ Channel/Billing/Settlement می‌رود. Lastsecond نشان می‌دهد مزیت اصلی بازار مصرف‌کننده این‌هاست:

- محتوای تور
- جستجو
- قیمت چندارزی
- رزرو/درخواست
- اعتماد/UGC
- SEO

Channel API یک تمایز B2B است، اما بدون Marketplace قابل استفاده، ارزش تجاری ندارد. پیشنهاد: قبل از Channel OAuth، حداقل این‌ها تکمیل شوند:

1. ADR-0024 (چندارزی/مالیات/BookingMode)
2. Tour Content Model
3. Offer Accommodation/Flight Options
4. Faceted Search
5. User Identity + Reviews
6. Request/Lead Engine
