# ADR-0017 — سیاست زبان لاگ: انگلیسی ثابت، پیام کاربر محلی

- **وضعیت:** Accepted (Locked)
- **تاریخ:** 2026-11-10

## زمینه

درخواست شده بود «لاگینگ چندزبانه» باشد. اما لاگ فنی چندزبانه، جستجو/تجمیع/هشدار را خراب می‌کند و باعث هزینه ترجمه بی‌فایده می‌شود.

## تصمیم

- **کد و لاگ فنی فقط انگلیسی.**
- **پیام کاربر** بر اساس زبان مخاطب (FA/EN/AR) ترجمه می‌شود.
- لاگ فنی شامل `ErrorCode` + `MessageKey` + `Locale` است، نه متن ترجمه‌شده.
- Audit Log شامل `Code` + `Locale` + Actor است؛ متن محلی در جدول notification/user message نگه‌داری می‌شود، نه در لاگ فنی.
- Enricherها: `TraceId`, `SpanId`, `TenantId`, `AgencyId`, `UserId`, `Module`, `ErrorCode`, `MessageKey`, `Locale`.
- PII Redaction اجباری.
- `traceId` به کاربر برگردانده می‌شود.

## پیامدها

**مثبت:** لاگ قابل جستجو، داشبورد یکدست، ترجمه فقط در لایه presentation.

**منفی:** برای پشتیبانی چندزبانه باید کد خطا را به پیام محلی map کرد (ابزار داخلی).
