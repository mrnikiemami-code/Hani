# ADR-0004 — MediatR 12.5.0 (آخرین نسخه Apache-2.0)

- **وضعیت:** Accepted (Locked)
- **تاریخ:** 2026-11-10

## زمینه

MediatR از نسخه ۱۳ به بعد لایسنس تجاری دارد. TravelCore نمی‌خواهد وابستگی لایسنسی ناخواسته ایجاد کند.

## تصمیم

- نسخه **12.5.0** قفل می‌شود (Apache-2.0).
- ارتقا به ۱۳+ فقط با ADR جدید و تأیید حقوقی/مالی.
- استفاده از `IRequest`/`IPipelineBehavior` در Application.
- Validation با FluentValidation و `ValidationBehavior`.

## الگو

```
Application/
  Commands/CreateOffer/
    CreateOfferCommand.cs
    CreateOfferCommandHandler.cs
    CreateOfferCommandValidator.cs
  Queries/GetOffers/
    GetOffersQuery.cs
    GetOffersQueryHandler.cs
    GetOffersQueryValidator.cs
```

## پیامدها

**مثبت:** لایسنس آزاد، اکوسیستم بالغ، الگوی آشنا.

**منفی:** عدم دریافت قابلیت‌های جدید ۱۳+؛ نیاز به بازبینی امنیتی دوره‌ای نسخه ۱۲.

## جایگزین‌ها

- پیاده‌سازی دستی CQRS: هزینه و ریسک بیشتر.
- MediatR 14 با لایسنس تجاری: رد شد.
